# DAW-Hub

## 🚀 Objetivo
Proyecto colaborativo de alumnos DAW de ThePowerFP para aprender DAW construyendo algo útil y real desde el primer día.  
Se trabaja en abierto: todos pueden proponer ideas, comentar y colaborar.

---

## 📜 Normas
- Todas las ideas son bienvenidas, incluso sin código.  
- Comentar y dar feedback antes de hacer pull requests.  
- Cada mini-tarea debe ser **pequeña y clara**.  
- Los commits deben ser claros y explicativos.  
- Se aprende revisando el código de otros y participando activamente.  

---

## 🛠 Cómo participar
1. Crear **issues** para proponer mini-tareas o funcionalidades.  
2. Hacer **pull requests** con pequeños cambios en el repositorio.  
3. Comentar y ayudar a mejorar ideas de otros compañeros.  
4. Revisar PRs de otros para aprender y aportar.  

---

## 📌 Mini-tareas iniciales sugeridas
- **Formulario de contacto básico:** HTML que recoja nombre y email, guardado en un JSON simulado.  
- **Página de recursos:** listado de enlaces útiles para DAW y programación.  
- **Mini-landing “Hola, soy alumno de DAW”**: HTML simple con tu nombre y lo que quieres aprender.  
- **Interfaz de contribuyentes:** mostrar los nombres de los alumnos que han hecho commits o PRs.

---

## 📢 Comunicación
- Todo el seguimiento y notificaciones se realiza en Discord → canal `#proyectos`.  

---

## 💡 Claves
- Empieza con **algo pequeño y útil** para que todos puedan participar desde el día 1.  
- Cada PR o commit debe ser **claro y revisable** .  
- Lo importante es **aprender juntos** y colaborar sin miedo a equivocarse.
